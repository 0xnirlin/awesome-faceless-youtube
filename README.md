# Awesome Faceless YouTube

A curated list of rules, data, tools and guides for people who run faceless YouTube channels, meaning channels built on narration, footage, animation or screen recordings instead of a presenter on camera. It starts with YouTube's own policies, because those decide what can earn money, then covers research, scripting, video makers, audio, editing, free tools, niches, Shorts, monetization, communities and automation.
